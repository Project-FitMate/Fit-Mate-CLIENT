# fit_mate_client

Feature-first + MVVM folder structure starter for the Fit Mate Flutter app.

## Project Structure

```text
lib/
├── core/
│   ├── constants/
│   ├── network/
│   ├── theme/
│   └── utils/
├── shared/
│   └── widgets/
├── features/
│   ├── upload/
│   ├── styling_condition/
│   ├── recommendation/
│   └── result/
└── main.dart
```

Each feature follows:

```text
feature/
├── model/
├── view/
├── viewmodel/
└── widget/
```

This PR is intended to establish the initial file layout only.
